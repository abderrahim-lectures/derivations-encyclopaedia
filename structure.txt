# Encyclopaedia of Derivations of Rings and Algebras: structure manifest.
# One line per part (P), chapter (C) or section (S). Fields are separated by "|".
#   P|<roman numeral>|<part title>
#   C|<NN>|<slug>|<chapter title>|<MSC codes to harvest, space separated>|<assignment rule>
#     The rule files a paper under the chapter for the monthly update and the
#     atlas: a case-insensitive regex on the title, or @pre1950 (published
#     before 1950), or @msc:<prefixes> (a primary MSC code with that prefix).
#     Empty rule: the chapter gets no papers automatically.
#   S|<NN>|<slug>|<section title>
#   Q|<zbMATH search string>
#     A narrow topic inside a broad MSC code, harvested with the codes:
#     "cc:16Y30 & ti:deriv*" takes the derivation papers of the near-ring
#     code and nothing else. The papers are filed by the chapter rules.
# tools/scripts/encyclopaedia/build-tree.sh turns this file into chapters/NN-slug/
# (one .tex per section) and chapters/index.tex. It never overwrites a section
# file that already exists, so written text is safe; a new line adds a stub.
# Chapter numbers are stable: renumbering breaks cross-references and the
# monthly update map, so add new chapters at the end of their part.
